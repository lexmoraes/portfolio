# 🚀 Alexsandro Moraes — Developer Portfolio

Portfolio desenvolvido com Angular para apresentar minha trajetória, projetos, habilidades e conquistas como desenvolvedor de software.

## 🌐 Acesse o Portfólio

O projeto está disponível em:

👉 **https://www.alexmoraes.dev**

## ✨ Sobre o projeto

Este projeto foi criado com foco em:

- Performance
- Responsividade
- Animações modernas
- Arquitetura escalável
- Experiência visual premium

O objetivo é centralizar meus principais projetos, experiências e conquistas acadêmicas/profissionais em uma aplicação moderna.

---

## 🛠️ Tecnologias utilizadas

- Angular
- TypeScript
- TailwindCSS
- Angular Material
- GSAP
